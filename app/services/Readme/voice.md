# Voice Service

## 1. Overview

The `voice_service.py` module implements the end-to-end voice interaction workflow for Nevark AI.

It allows a user to submit an audio file and receive an audio response generated by the AI assistant.

The module connects three major components:

- **Speech-to-Text (STT):** Faster-Whisper converts incoming audio into text.
- **AI Chat Processing:** The chat service processes the recognized text and generates an AI response.
- **Text-to-Speech (TTS):** ElevenLabs converts the AI response into an MP3 audio file.

The main function, `process_voice()`, orchestrates these components and returns the generated audio using FastAPI's `FileResponse`.

| `transcribe_audio()` | Converts incoming audio into text using Faster-Whisper |
| `process_chat()` | Processes the transcript and generates an AI response |
| `generate_audio()` | Converts the AI response into an MP3 file using ElevenLabs |

The module acts as an orchestration layer, connecting the speech engines with the existing chat-processing service.

## 3. Core Function: `process_voice()`

```python
async def process_voice(audio_file):
```

This asynchronous function handles the complete voice interaction workflow.

It accepts an uploaded audio file, transcribes it, sends the transcript to the AI chat service, generates spoken output, and returns the resulting audio file.

### Input parameter

| Parameter | Type | Description |
|---|---|---|
| `audio_file` | Uploaded file object | Audio file supplied by the calling API route |

The function expects an object that supports asynchronous reading through `audio_file.read()`.

### Return value

The function can return:

- A FastAPI `FileResponse` containing the generated MP3.
- A dictionary containing an error status and error message if an exception propagates.

## 4. Complete Voice Processing Pipeline

### Step 1: Initialize the temporary file path

```python
temp_path = None
```

The variable stores the location of the temporary audio file.

It is initialized to `None` so that the cleanup section can determine whether a temporary file was successfully created.

### Step 2: Create a temporary audio file

```python
with tempfile.NamedTemporaryFile(
    delete=False,
    suffix=".wav"
) as temp:

    content = await audio_file.read()

    temp.write(content)

    temp_path = temp.name
```

The uploaded audio is read and written into a temporary file.

The operations are:

1. `NamedTemporaryFile()` creates a temporary file.
2. `delete=False` prevents automatic deletion when the file handle closes.
3. `suffix=".wav"` assigns a WAV file extension.
4. `await audio_file.read()` reads the uploaded audio bytes.
5. `temp.write(content)` writes those bytes into the temporary file.
6. `temp.name` stores the temporary file path in `temp_path`.

The temporary file is retained after the `with` block so that the Whisper engine can access it.

**Important:** Assigning the `.wav` extension does not convert the uploaded audio into WAV format. The original uploaded bytes are written unchanged.

### Step 3: Convert audio into text

```python
transcript = transcribe_audio(
    temp_path
)
```

The temporary audio file path is passed to `transcribe_audio()` from:

`app/core/whisper_engine.py`

The Faster-Whisper engine:

1. Loads the already initialized Whisper model.
2. Processes the supplied audio file.
3. Uses the configured English transcription setting.
4. Applies voice activity detection filtering.
5. Extracts recognized speech segments.
6. Combines the segments into a single text string.

The resulting transcript is stored in `transcript`.
